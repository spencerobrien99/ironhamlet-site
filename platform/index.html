Platform

One exercise environment, three views of the same incident.

Participants see the plant the way a real control room does: the process itself, the control layer that runs it, and the evidence left behind on the network.

What participants work with

The process, the controller, and the evidence.

  • The process: a two-tank water-treatment plant with level instrumentation, fill and discharge valves, and safety interlocks, rendered in 3D.
  • The control layer: compiled PLC logic running the plant over Modbus TCP, with an operator HMI showing levels, valve states, alarms, and messages.
  • The evidence layer: captured industrial network traffic in a searchable store, plus a run record and after-action report for every scenario.

Capabilities

What the platform does today.

Each capability below is implemented in the current release and has been exercised on the running plant.

Browser-accessible exercises

The operator HMI, the exercise console, and the investigation tools all open in a standard web browser.

For your team: no plant hardware or specialist software to install on participant machines.

Simulated industrial process

A two-tank water-treatment plant with an intake tank and a distribution tank. Levels rise and fall and valves cycle under closed-loop control.

For your team: practice reading a process that behaves like a process, not a scripted animation.

OpenPLC controller interactions

The plant is run by compiled control logic on an OpenPLC runtime over Modbus TCP, including interlocks that correct unsafe valve states.

For your team: see how real control logic responds when an attacker issues commands it would never issue itself.

FUXA operator HMI

A browser-based operator display with tank levels, valve states, a process-flow schematic, alarms, and a live incident message feed.

For your team: the operator's view is part of the exercise, including when that view is the target.

Attack and investigation workflows

Instructor-launched scenarios run against the live plant. An isolated, browser-launched attacker workspace is available for guided offensive demonstrations.

For your team: rehearse the full loop from symptom to evidence to recommendation.

OpenSearch security telemetry

Modbus and network traffic is captured with Zeek during each run and shipped into OpenSearch, where it can be queried and filtered in a dashboard.

For your team: investigate with the same kind of evidence an OT security team relies on.

Scenario execution and reset

Scenarios launch from the exercise console. Reset independently checks valves, levels, and controller health, and returns the plant to a known-good state.

For your team: every incident starts from the same verified baseline.

Structured after-action reporting

Each run produces an after-action report: an executive summary, the exercise timeline, the attack and controller response, MITRE ATT&CK for ICS mapping, scoring, and an instructor assessment checklist.

For your team: a written record that anchors the debrief and outlasts the day.

After-action report

Separating what the attacker did from what the process suffered.

A write that is accepted by the controller is not the same as a plant that was harmed. The after-action report keeps the two apart, so the team's conclusions rest on evidence.

Executive summary

Whether the attack was accepted at the protocol level, whether any process consequence was observed, and how the controller responded.

Timeline and evidence

Exercise messages in the order they fired, the attempted attack, the controller's correction, and the captured network evidence.

Scoring and assessment

Objective criteria computed from the run record, kept separate from instructor-assessed decision quality.

Current scope

What to expect from this release.

IronHamlet is early-stage. These are the boundaries of what we offer today.

  • One standard exercise plant: a two-tank water-treatment process.
  • Two primary scenarios: unauthorized command and manipulation of view.
  • Exercises are instructor-facilitated. Self-service operation is not offered.
  • Delivery logistics, including remote or on-site facilitation, are agreed for each engagement.
